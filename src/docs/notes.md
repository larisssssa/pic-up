# PicUp - a photographer application

PicUp is an application for photographers to organize their business through project and client management. PicUp offers the following capabilities:
 - For Projects:
    - Create new projects
    - View, sort, and filter a list of all projects
     - View Project Details
     - Update project status
     - Add and remove images from a project
 - For Clients:
     - View Client List
     - View and update Client Details
